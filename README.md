## 🧠 My Engineering Approach

I follow a **scenario-based, hands-on learning approach**.

Instead of only studying:

`Technology → Commands → Certification`

I focus on:

`Problem → Investigate → Build → Break → Troubleshoot → Fix → Verify → Automate → Document`

My goal is to develop the ability to take a real-world engineering problem and figure out how to solve it.
